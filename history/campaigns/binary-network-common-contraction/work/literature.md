# Literature and inherited evidence

[Marchand et al., 2025](https://link.springer.com/article/10.1186/s13015-025-00283-9).
Definition 1 and Proposition 1 define admissible internal-arc contractions.
Definition 5 and Proposition 5 characterize them by connected bags with an
acyclic exact quotient and matching leaf parents. Theorem 9 bounds the known
hardness construction's degree by ten; the next paragraph and conclusion leave
binary inputs open. The new search `"common contractions" "binary" phylogenetic
2026` located no matching later resolution. This is bounded coverage, not a
certificate of priority. The known source construction uses connected bags
for the two sides of a Set Splitting solution.

The article's construction prose contains endpoint-name/arc inconsistencies;
use its mathematical degree and witness conditions, not an unverified literal
transcription. No prior construction is claimed as new here.

The earlier [Tree Containment counterexample](../../../research/evidence/binary-network-contraction/README.md)
is inherited, not a new round: a nine-vertex binary network displays a balanced
four-leaf tree but cannot contract to it. The prepare self-test uses this as a
negative regression under the actual contraction definition.

Experience search: `contraction|reticulation|binary.network` in
research/experience. The [reticulation-stack entry](../../../research/experience/binary-reticulation-stack-nae.md)
uses a proper-forest condition requiring exactly one same-color parent. Common
contraction instead requires weak connectivity of each bag and an acyclic
quotient. That entry's NAE gadget therefore cannot be transferred unchanged.
BFS contraction entries concern parent-compatibility networks, not this target.

## Complete-candidate novelty check

On 2026-09-16 searched `"maximum common contraction" "binary" NP-hard 2026`
and `phylogenetic network "binary" "contraction" "Set Splitting"`.
Results again identify the 2025 primary article and its WABI 2024 predecessor;
no matching later binary-input theorem was located in this bounded search.
The exact contribution claimed for review is binary-input NP-completeness with
polynomial arbitrary-witness recovery and linear graph size, using a variable
threshold and an unbounded leaf set. It does not claim the known degree-ten
result, constant threshold hardness, bounded reticulation level or edit-distance
hardness. The connected incidence encoding, leaf-parent forcing and quotient
characterization are credited to the primary paper. The proposed new combination
is an all-port binary spine, reversed variable taxa, partial-assignment recovery
and separation paths overcoming the number of free variable bags. Novelty and
significance remain separate reviewer questions; search absence does not certify
priority or correctness.

The independent review additionally identifies Proposition 7 / Figure 3 as the
explicit antecedent for reversed endpoint ancestry. This attribution is applied
in the proof and manuscript; endpoint reversal alone is not claimed as new.
